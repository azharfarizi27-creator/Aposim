## 📖 Deskripsi Proyek
Proyek yang saya ambil dalam pengembangan C# ini berjudul:

**Aplikasi Point Of Sale (POS) + Inventory Management**

Aplikasi ini dibuat untuk **mempermudah perusahaan dagang** dalam mengelola seluruh sistem operasional, mulai dari:
- Pengelolaan barang dagang
- Data customer dan supplier
- Proses penjualan
- Laporan dan monitoring data

Aplikasi ini juga:
- Mempermudah **kasir** dalam melakukan transaksi penjualan
- Membantu **manajer** dalam melihat data penjualan, daftar produk, dan laporan toko secara keseluruhan

---

## 🔐 Role & Fitur Aplikasi

### 👤 Admin
Admin memiliki akses penuh terhadap sistem, dengan fitur:
- CRUD User (Admin, Kasir, Manajer)
- CRUD Customer
- CRUD Supplier
- CRUD Data Master Produk
- Report / Laporan

---

### 🧑‍💼 Kasir
Kasir memiliki fitur utama:
- Sistem penjualan yang **mudah digunakan**
- Proses transaksi yang cepat dan efisien

---

### 📊 Manajer
Manajer memiliki fitur monitoring dan laporan:
- Laporan penjualan **hari ini**
- Laporan penjualan **bulanan**
- Informasi **kas toko**
- Akses seluruh laporan
- Export laporan ke **PDF** dan **Excel**
